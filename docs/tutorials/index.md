# Tutorials

Tutorials are different from guides. Guides explain what something does. Tutorials are scenario-driven — you follow a specific person through a specific situation, typing the same prompts they type, seeing roughly what they see.

Each one takes under 15 minutes to complete alongside Claude Code.

> **Tip:** These tutorials are designed to run in parallel with Claude Code. Open Claude Code alongside this page and type the prompts as you read — the output you see will differ (it's based on your real context), but the shape of the interaction will match.

## Pick your starting point

**New to haku?**
Start with [Set up your profile](setup-profile.md). It's the foundation everything else builds on — and it only takes about 10 minutes. Then try [Set up your stakeholder radar](stakeholder-radar.md).

**Have a promo cycle coming up?**
Start with [Log a win and turn it into a story](log-a-win.md). Even if you've been logging, the curation step is where most people are surprised.

**Building an AI feature?**
Start with [Sanity-check an AI feature before building it](ai-feature-check.md). It runs a fictional feature pitch through the anti-hype stack — the-reducer, the-scientist, the-eval-designer.

**Running a team?**
Start with [The Friday leadership review](friday-review.md). A 15-minute weekly routine that touches wins, stakeholders, and patterns.
